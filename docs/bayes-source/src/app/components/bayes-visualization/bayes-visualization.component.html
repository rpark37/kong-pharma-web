Therapeutic Tests (Bayes' Theorem)

If a person gets a positive result from a therapeutic test, how likely are they to have the disease?

See morphcharts.com for more information on the MorphCharts library.

This visualization shows several views of a synthetic dataset to illustrate sensitivity and specificity in a therapeutic test. The data is generated using values for people count, test specificity & sensitivity, and a prior (occurrence of the disease in the sample population).

Use the Next and Prev buttons to step through the views, and adjust the values to see how it affects the visualizations.
