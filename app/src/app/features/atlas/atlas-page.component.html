{{ parts().length | number }} individual meshes and {{ concepts().length | number }} named concepts from an adult male reference anatomy.

This reference does not contain every human structure or variation. Named concepts can contain multiple pieces; each source mesh is represented once.

Colors and system groupings are designed for exploration. Shapes are bounding-box proxies of the simplified web geometry. This is an anatomical reference, not a diagnostic or surgical tool.
